Kleines Programm aus langeweile gemacht, da mein Download Ordner mir langsam zu unübersichtlich wurde.
Free to use

Datei Organisierer

Ein Python-Skript das den Downloads-Ordner automatisch 
aufräumt und Dateien nach Typ in Unterordner sortiert.

Was es macht
- Bilder  /Bilder
- Videos  /Videos  
- Dokumente  /Dokumente
- Programme  /Programme
- Alles andere  /Sonstiges

Benutzung
python organiser.py

Technologien
Python 3 | os | shutil
